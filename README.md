# Gun-code-search
三角洲改枪码便携检索工具

一个无需服务器、纯本地运行的 **改枪码数据检索 / 维护** 工具

---

## 特性

- **即时检索**：输入枪械名（如 `M7`、`腾龙`、`MP5`）即自动过滤，大小写不敏感，仅匹配字段
- **一键复制**：鼠标点击结果卡片，改枪码即可复制到剪贴板，带成功提示
- **完全离线**：所有数据内嵌于 HTML，双击即可运行，无需服务器与网络
- **可持续更新**：配合更新工具可自助更新新版本

---

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `GunCodeSearch.html` | 检索页面，完整数据库内嵌其中（初始约 274 条） |
| `GunCodeUpdater.html` | 更新工具，用新数据重新生成检索页面 |
| `guncodes.txt` | 数据源示例（纯文本，每行一条、可替换） |

> `GunCodeSearch.html` 与 `guncodes.txt` 相互独立：数据库已写入检索页内，`guncodes.txt` 作为数据源参考，修改它不会影响已经生成的检索页

---

## 快速上手

### 使用检索页面

1. 双击打开 `GunCodeSearch.html`
2. 在搜索框输入枪械名（如 `M7` / `腾龙` / `ASVAL`）
3. 点击任意一条结果即可复制改枪码

### 更新数据库

由于浏览器安全限制，网页无法直接覆写磁盘上的 HTML 文件，因此更新通过 **“生成新文件并下载”** 的方式完成：

1. 双击打开 `GunCodeUpdater.html`。
2. 左侧「模板文件 / .html」：选择 `GunCodeSearch.html`。
3. 右侧「新数据库 / .txt」：选择 `guncodes.txt`（或你自己的新数据文件）。
4. 点击 **「更新并下载」**，浏览器会下载一个已内嵌新数据的全新 `GunCodeSearch.html`

> 注意,每一次更新操作会清除所有旧数据

> 校验部分  .html检测含 `EMBEDDED_DB` 的模板  .txt检测符合数据行格式的内容

## 数据格式

数据库严格按每行一条的格式排列：

```text
评级 简介-改枪码
```

| 字段 | 分隔 | 说明 |
| --- | --- | --- |
| 评级 | 与简介用**空格**隔开 | 如 `S+`、`S`、`A`、`未定级` |
| 简介 | 与改枪码用**`-`**隔开 | 例如 `满改M7双流共振骨架托顶配版` |
| 改枪码 | `-` 之后 | 纯字母数字字符串 |

**示例：**

```text
S+ 满改M7双流共振骨架托顶配版-6KJK60G0B1RRH96DI8AIT
S   性价比改法ASVAL锚点后托红点40万-6L6UJEG0BAC7RIM3B0293
未定级 性价比跑刀SG552稳定版11万-6KF7JGC0E0LL9IRHUI52L
```

> 解析规则：改枪码恒在行尾且不含 `-`，故从行尾**取最后一个 `-`** 切出改枪码；前半段再按**第一个空格**切出评级与简介。这样即使简介里含有 `-`（如 `新-PKM…`）也能正确解析。

## 技术说明

- 纯 HTML + CSS + JavaScript，无任何外部依赖、无框架、无构建步骤
- 数据库存储在检索页内的 `const EMBEDDED_DB` 模板字符串中
- 更新工具通过替换该模板字符串并触发浏览器下载，生成自包含的新 HTML
- 支持现代桌面及移动浏览器（需支持 `navigator.clipboard` / `FileReader` / `Blob` / 模板字符串）
